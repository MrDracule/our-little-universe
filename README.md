
# ♡ Our Little Universe

Um pequeno presente digital desenvolvido para celebrar
dois meses de namoro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Tela inicial interativa
- Contador de relacionamento
- Linha do tempo
- Carta de amor interativa
- Player de música
- Cartões com motivos para amar
- Surpresa final
- Animações e efeitos visuais
- Layout responsivo

## Estrutura

- assets/css: estilos do projeto
- assets/js: funcionalidades JavaScript
- assets/images: imagens e elementos decorativos
- assets/music: músicas do projeto
- assets/fonts: fontes locais

## Como executar

1. Abra a pasta no Visual Studio Code.
2. Instale a extensão Live Server.
3. Abra o index.html.
4. Clique em Go Live.
